## 🚀 Установка

### Шаг 1: Найди папку профиля Firefox

1. Открой **Firefox**
2. В адресной строке введи: **`about:support`**
3. Найди строку **"Папка профиля"** (Profile Directory)
4. Нажми **"Открыть папку"** (Open Directory)

### Шаг 2: Создай папку chrome

В папке профиля:
1. Создай новую папку **`chrome`** (строчными буквами!)
2. Открой папку `chrome`

### Шаг 3: Скопируй файлы темы

1. Скопируй **всё содержимое** из `MacOS-Firefox-theme` в папку `chrome`
2. Должна получиться структура:

```
[Профиль Firefox]/
└── chrome/
    ├── customChrome.css
    ├── MacTahoe/
    ├── README.md
    └── README_EN.md
```

### Шаг 4: Создай или отредактируй userChrome.css

В папке `chrome` создай файл **`userChrome.css`** и добавь:

```css
/* MacOS Window Controls Theme */
@import "MacTahoe/theme.css";
@import "customChrome.css";
```

💡 **Если файл уже существует** - добавь только:
```css
@import "customChrome.css";
```

### Шаг 5: Включи поддержку кастомных стилей

1. В адресной строке введи: **`about:config`**
2. Нажми **"Принять риск и продолжить"**
3. Найди: **`toolkit.legacyUserProfileCustomizations.stylesheets`**
4. Установи значение **`true`** (двойной клик)

### Шаг 6: Перезапусти Firefox

1. **Полностью закрой Firefox** (все окна)
2. Открой Firefox заново
3. **Готово!** 🎉

## 🔧 Настройка

### Изменить отступ от левого края

Открой `customChrome.css` и найди:
```css
#nav-bar {
  padding-left: 96px !important;  /* ← Измени это значение */
}
```

- Меньше (`70px`) - кнопки ближе к краю
- Больше (`120px`) - кнопки дальше от края

### Изменить расстояние между кнопками

```css
#nav-bar .titlebar-buttonbox-container {
  gap: 4px !important;  /* ← Расстояние между кнопками */
}
```

## ❓ Устранение неполадок

### Тема не работает?

✅ Проверь путь: `[Профиль]/chrome/customChrome.css`  
✅ Убедись: `toolkit.legacyUserProfileCustomizations.stylesheets` = `true`  
✅ Перезапусти Firefox полностью  
✅ Проверь `userChrome.css`: должна быть строка `@import "customChrome.css";`

### Кнопки остались справа?

✅ Проверь порядок импорта в `userChrome.css`  
✅ `@import "customChrome.css";` должен быть **после** `@import "MacTahoe/theme.css";`  
✅ Полностью перезапусти Firefox

### Хочу вернуть стандартный вид?

Закомментируй в `userChrome.css`:
```css
/* @import "customChrome.css"; */
```

## 📝 Технические детали

### Что изменено

1. **customChrome.css** - позиционирование слева, правильный порядок кнопок
2. **Все состояния**: обычное, при наведении, при нажатии, неактивное окно
3. **Обе темы**: светлая и темная

### Измененные файлы

**Кнопка закрытия (красная):**
- `titlebutton-close.svg` / `titlebutton-close-dark.svg`
- `titlebutton-close-hover.svg` / `titlebutton-close-hover-dark.svg`
- `titlebutton-close-active.svg` / `titlebutton-close-active-dark.svg`
- `titlebutton-close-backdrop.svg` / `titlebutton-close-backdrop-dark.svg`

**Кнопка разворачивания (зеленая):**
- `titlebutton-maximize-*.svg` / `titlebutton-unmaximize-*.svg`
- Все варианты: normal, hover, active, backdrop (light + dark)

**Кнопка сворачивания (желтая):**
- `titlebutton-minimize-*.svg`
- Все варианты: normal, hover, active, backdrop (light + dark)
